# Dia XX - Formulario completo (React)

Proyecto de ejemplo con un formulario de registro de estudiante que usa múltiples tipos de input y validaciones.

Instrucciones rápidas:

```bash
npm install
npm run dev -- --host
```

Requisitos cumplidos:
- Campos controlados con useState
- Validación básica de email
- Checkbox de aceptar términos habilita/deshabilita el envío
- Valor del range mostrado en tiempo real
- Vista previa de la imagen subida
